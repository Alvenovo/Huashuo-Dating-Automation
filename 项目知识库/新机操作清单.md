> 照着「步骤」敲，对一下「预期结果」。**对不上就停，别往下走。**

> - **机器**：**测试机** = 新发下来那台；**控制机** = 投任务、出报告那台（当前 = 包源机 `LAPTOP-VS5F7HF4`）。

## 六 B · 命令行下载（要一个令牌，只在不能开浏览器时用）

**做法**

1. 用**有仓库权限的账号**登录 GitHub，打开
   `https://github.com/settings/personal-access-tokens/new?name=hall-auto-download&contents=read`
2. **Repository access** 选 `Only select repositories` → 勾上 `Huashuo-Dating-Automation`
3. **Permissions** → **Repository permissions** → **Contents** 选 **Read-only**
   —— **只要这一个权限就够了**，其他全部留 `No access`
4. 拉到底点 `Generate token`；页面顶部出现一串 `github_pat_` 开头的字符串
5. 敲：

   ```powershell
   $ProgressPreference = "SilentlyContinue"
   [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
   cd C:\Users\你的用户名\Desktop

   $tok = Read-Host "粘贴令牌"          # 粘贴后回车，屏幕上不会显示

   Invoke-WebRequest -Headers @{ Authorization = "Bearer $tok" } `
     -Uri "https://api.github.com/repos/Alvenovo/Huashuo-Dating-Automation/zipball/main" `
     -OutFile repo.zip -MaximumRedirection 5

   Expand-Archive repo.zip -DestinationPath _tmp_repo
   $inner = Get-ChildItem _tmp_repo | Select-Object -First 1
   Move-Item $inner.FullName Huashuo-Dating-Automation
   Remove-Item _tmp_repo -Recurse -Force
   Remove-Item repo.zip -Force

   # 清理：别把令牌留在窗口变量和命令历史里
   Remove-Variable tok
   Clear-History
   Remove-Item (Get-PSReadlineOption).HistorySavePath -ErrorAction SilentlyContinue
   ```

**预期结果**

```
C:\Users\你的用户名\Desktop\Huashuo-Dating-Automation\
```

**对不上就停**：

- `401 Unauthorized` → 令牌复制不完整，或粘贴时带了空格/换行。重新生成一个。
- `404 Not Found` → **权限不够时 GitHub 会假装"仓库不存在"**。回第 2 条确认勾上了本仓库。
- `403 Forbidden` → 令牌过期，或 **Contents 不是 Read-only**。回第 3 条。
- 卡住不动 / 重定向出错 → 改用这行（`curl.exe` 是系统自带的）：

  ```powershell
  curl.exe -L -H "Authorization: Bearer $tok" -o repo.zip "https://api.github.com/repos/Alvenovo/Huashuo-Dating-Automation/zipball/main"
  ```

⚠️ **令牌是密码级的凭据**：不能写进任何文件、不能贴进聊天或群里。上面最后三行就是清理命令，别省。

# 步骤十一 · 填凭据文件

**机器**：测试机 ｜ **终端**：不用终端（用记事本/编辑器改文件） ｜ **权限**：—

**做法**

打开仓库根目录的 `farm_node.env`，把等号后面填上真实值：

```ini
HALL_TEST_USER=大厅测试账号
HALL_TEST_PASSWORD=大厅测试密码
HALL_MS_USER=微软邮箱

HALL_SHARE_USER=hallshare
HALL_SHARE_PASSWORD=共享盘密码
```

**预期结果**

值不加引号；用不上的留空（对应套件会自动跳过，不影响其他套件）。

⚠️ **换测试号只改这一处**（`HALL_TEST_USER`；密码不同就一并改 `HALL_TEST_PASSWORD`）。
**控制机侧一处都不用动** —— 凭据按设计只放节点本地，不进共享盘、不进任务文件。
⚠️ **不需要重跑 bootstrap** —— 脚本每次取任务时会重新读这个文件。
⚠️ **改完要在「新开的窗口」里起 agent**：窗口里的 `$env:HALL_TEST_USER` 优先级**高于**本文件，
会把它盖掉。旧窗口里设过的话，改了文件也还是用旧号（而且不报错）。
⚠️ **不填的话登录套件会静默跳过**：不报错，但一条都没真跑，报告上一片黄，你会以为"跑过了没问题"。
⚠️ `HALL_BIND_PHONE` **留空即可** —— 它默认回退到 `HALL_TEST_USER`（要绑的号≠登录的号时才单独填）。
