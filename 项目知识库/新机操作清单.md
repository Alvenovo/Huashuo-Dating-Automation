# 新测试机操作清单（纯步骤）

**这份只写动作。** 为什么这么做、报错了怎么查 → 看《测试机操作手册.md》。
每一步都带「应该看到什么」，**对不上就停下，别往下走**。

---

## 0. 先要齐这些

| 东西 | 找谁要 |
| --- | --- |
| 管理员权限的账号 | 组长 / IT |
| 共享盘账号 + 密码（账号通常叫 `hallshare`） | 组长 / 负责人 |

## 1. 装 Python

1. 打开 `https://www.python.org/downloads/windows/`
2. 下载 **64 位**安装包（Windows installer 64-bit）
3. 运行安装包，**第一屏最下面勾上 `Add Python to PATH`**，再点 `Install Now`
4. 装完**开一个新的 PowerShell 窗口**，敲：

   ```powershell
   python --version
   ```

**应该看到**：`Python 3.x.x`

**对不上就停**：
- 弹出微软商店 → 去 设置 → 应用 → 高级应用设置 → 应用执行别名，关掉 `python.exe` 和 `python3.exe`，回第 1 步重装
- 报 `not recognized` → 勾 PATH 那步漏了，回第 3 步重装

---

## 2. 把代码放到桌面

**三条路选一条。**

### 1A · 有 Git

```powershell
cd C:\Users\你的用户名\Desktop
git clone https://github.com/Alvenovo/Huashuo-Dating-Automation
cd Huashuo-Dating-Automation
```

第一次会弹 GitHub 登录。先敲这行再重试：

```powershell
git config --global credential.helper manager
```

### 1B · 没 Git（不用装任何东西）

```powershell
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
cd C:\Users\你的用户名\Desktop
$tok = Read-Host "粘贴 GitHub 令牌"
Invoke-WebRequest -Headers @{ Authorization = "Bearer $tok" } `
  -Uri "https://github.com/Alvenovo/Huashuo-Dating-Automation/archive/refs/heads/main.zip" `
  -OutFile repo.zip
Expand-Archive repo.zip -DestinationPath .
Rename-Item Huashuo-Dating-Automation-main Huashuo-Dating-Automation
cd Huashuo-Dating-Automation
Clear-History
Remove-Item (Get-PSReadlineOption).HistorySavePath -ErrorAction SilentlyContinue
```

### 1C · 无网、无令牌

从**已经铺好**的机器拷整个目录过来。拷之前**删掉这三样**：

- `config.local.yaml`
- `farm_node.env`
- `reports\` 整个目录

拷完先试：

```powershell
.\.venv\Scripts\python.exe --version
```

报错就删掉 `.venv` 目录（让脚本自己重建）。

### 检查

```powershell
dir
```

**应该看到**：`AGENTS.md`、`tools`、`tests`、`hall_auto`、`config.yaml`

## 3. 开管理员窗口，设三个变量

开始菜单 → 右键 → **终端(管理员)** / **Windows PowerShell(管理员)**

**就在这个窗口里**，依次敲：

```powershell
$env:HALL_SHARE_USER = "hallshare"
$env:HALL_SHARE_PASSWORD = "<共享盘密码>"
$env:HALL_FARM_ROOT = "\\LAPTOP-VS5F7HF4\hall-farm"
```

**检查**：

```powershell
echo $env:HALL_FARM_ROOT
```

**应该看到**：`\\LAPTOP-VS5F7HF4\hall-farm`

看不到 → 你是在普通窗口设的。关掉，重开管理员窗口，回到本步开头。

---

## 4. 跑铺环境脚本

**在同一个管理员窗口里**，接着敲：

```powershell
cd C:\Users\你的用户名\Desktop\Huashuo-Dating-Automation
powershell -NoProfile -ExecutionPolicy Bypass -File tools\bootstrap_machine.ps1
```

两个可选参数：

```powershell
# 节点名要用 R01 这种编号时（必须和控制机 dispatch --nodes 里写的完全一致）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\bootstrap_machine.ps1 -NodeId R01

# 系统盘空间紧张时，指到别的盘
powershell -NoProfile -ExecutionPolicy Bypass -File tools\bootstrap_machine.ps1 -InstallerDir "D:\Test\大厅"
```

**耗时 5-15 分钟，中途别关窗口。**

**应该看到**（结尾长这样）：

```
[OK] 环境自检
[OK] 虚拟环境与依赖
...
[OK] 提权计划任务
[OK] 自检 tests/unit
结果：全部通过，本机已可跑批
```

**对不上就停**，把屏幕上的输出整段留好。

脚本最后会打印一个报告路径：`reports\bootstrap\bootstrap_<机器名>_<时间>.json`

## 5. 填凭据文件

打开仓库根目录的 `farm_node.env`，把等号后面填上真实值：

```ini
HALL_TEST_USER=大厅测试账号
HALL_TEST_PASSWORD=大厅测试密码
HALL_MS_USER=微软邮箱

HALL_SHARE_USER=hallshare
HALL_SHARE_PASSWORD=共享盘密码
```

**规则**：值不加引号；用不上的留空。

---

## 6. 验证凭据读到了

**在仓库根目录**敲：

```powershell
.\.venv\Scripts\python.exe -X utf8 -c "from pathlib import Path; from hall_auto.env_pack import build_suite_env, credential_status; env,_=build_suite_env(node_env_path=Path('farm_node.env')); print(credential_status(env))"
```

**应该看到**：`password_login: True` 之类（填了就是 `True`）

`node_env_path=Path('farm_node.env')` 这段**不能省**。

## 7. 验证共享盘农场

```powershell
net use \\LAPTOP-VS5F7HF4\hall-farm /user:hallshare "<共享盘密码>" /persistent:yes
dir \\LAPTOP-VS5F7HF4\hall-farm
```

**应该看到**：`tasks`、`done`、`results`、`logs` 四个文件夹

## 接下来跑批

**取一次任务**：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools\farm_agent.py --once
```

**常驻等任务**：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools\farm_agent.py --loop
```

**不走共享盘，本机单跑**：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools\farm_agent.py --local launch
```

跑批的完整流程（投任务 → 看进度 → 出报告）见《测试机操作手册.md》第三部分。
