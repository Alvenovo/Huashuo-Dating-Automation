# 探壳结论（写断言前必读）

控件图、定位坑、oracle 口径。每条都是本机探针实测出来的，换版本/换机器要复核。控件清单用表格（控件 | aid | 用途 | 坑），叙事性坑用 bullet。

## 窗口与就绪

- 首装/升级后首跑先出**独立顶层窗「权限确认窗口」**（同意/取消），点完同意主窗口才出现 → `wait_main_window` 等主窗口前先关前置窗。
- 大厅**会恢复上次的页面**（实测首跑落在设置/关于页）→ 就绪判定缺结构且存在 `BackBtn` 时点返回回首页。
- **登录后主窗口的 UIA Name 从「华硕大厅」变成「华硕应用商店」**（Win32 标题不变，2026-09-16 实测）：`wait_main_window` 返回的 WindowSpecification 按 title_re 匹配 UIA Name，登录态下解析**永远失败**（ElementNotFoundError，重试无用）。登录态要操作主窗口必须用 `launch.concrete_main(pid, title_contains)` 按 Win32 标题 + pid 重包具体 wrapper。退出登录后是否恢复未验证。
- **换 Win32 枚举必须自己过滤可见性**：`EnumWindows` 会把进程的隐藏消息窗（`Default IME`、`MSCTFIME UI`、`.NET-BroadcastEventWindow`、`Hidden Window` 等）也列出来，UIA 的 Desktop 枚举不会 → 顶层窗过滤要加 `IsWindowVisible`，否则全被当成「未知弹窗」直接 raise。
- 就绪循环里 `main.handle` / `main.element_info.process_id` 实测各 ~1s/次，是窗口生命周期内的**不变量**，必须循环外取一次缓存传进去，别每轮重取（第 24 条二次根因）。

## 首页 / 导航

- 结果页下方挂第三方广告位，节点坐标在窗口外 → 标题只从主窗口矩形内的「安装/打开/更新 X」主按钮取。
- 主按钮命名三处不一致：结果页 `安装 {名}`、首页 `安装应用：{名}`、详情页只有 `一键安装`。
- 搜索框 `SearchBarInput` 是原生 `Edit`，WebView2 内容 UIA 可读 → 不需要 Playwright。

## 厂商安装器 / 卸载器（只能用 Win32，UIA 是瞎的）

网易云安装器是 NSIS，UIA 报 0 个 descendants、还把每个子控件误报成独立顶层窗（class 叫 `Button`/`Edit`/`Static`、名字全空）→「按控件名找按钮」「枚举 descendants」两条路都死。换 Win32 全通：顶层标准对话框 `#32770`「网易云音乐 安装」，子控件 `WM_GETTEXT` 可读。探针 `tools\probe_win32.py`。

| 按钮 | 识别方式 | 坑 |
| --- | --- | --- |
| 关闭 | 文字 `关闭(&L)` | 要连 `(&L)` 一起剥掉才命中白名单 |
| 取消 | 文字 `取消(&C)` | 同上剥 `(&C)` |
| 上一步 | 文字 `< 上一步(&P)` | |
| 立即安装 | **自绘无文字**，按面积认 | 360x60=21600；关闭叉 36x36=1296；协议链接最大 144x25=3600 |

- **卸载器比安装器更坑**（2026-09-15 实抓）：大厅点「卸载」拉起 NSIS 卸载器，映像解包到 `%TEMP%\~nsuA.tmp\Au_.exe`（**不在下载目录**），对话框「网易云音乐 卸载」，卸完那页变「网易云音乐 卸载/ENABLECANCEL」。确认页有**两块尺寸位置完全相同的自绘按钮**（都 360x60=21600），OCR 出来**左「再想想」=取消、右「狠心卸载」=确认**；而控件树里被皮肤藏的文字按钮是 `卸载(&U)` 在左、`取消(&C)` 在右 —— **左右正好相反，按几何猜必点错**。唯一可靠点法：`BM_CLICK` 隐藏的 `卸载(&U)`（隐藏不影响 BM_CLICK，提权实测 3s 后注册表条目消失）。卸完那页只剩一块来历不明的自绘大按钮，**别点**，改点隐藏文字「关闭」，否则可能把应用又拉起来。
- **分层窗截图要用 `PrintWindow` 的 `PW_RENDERFULLCONTENT`(flag=2)**：flag=0 和整屏裁剪对这类窗都是纯空白（`distinct_colors=1`），flag=2 才有内容（6000+ 色）。走 Win32 前的兜底，现用不上但结论留着（`tools\probe_installer.py`）。
- **绿色单文件应用当不了夹具**：装 = 下到 `C:\AsusMCenterDownload` 直接运行，**从不写卸载注册表条目**、大厅卸载列表从不出现、详情页永远停「一键安装」→「装上/卸掉」无从断言；它自己还要提权启动（非提权 `WinError 740`）。映像同样落下载目录，**按映像认安装器时必须排除**，否则误当向导去点、甚至被收尾 taskkill 打死。夹具只能选带安装器的大厂应用（网易云：装完 55s 内注册表就有，卸载器 `UnInstall.exe /S` 静默卸干净）。
- 下载目录 `C:\AsusMCenterDownload` 会留安装包（网易云 165MB 装完仍在），属缓存不算缺陷，但跑完要清，否则下次装同名应用可能复用旧包。

## WorkBuddy 入口

- **入口定位两个坑**：①WB 文案被 UIA 拆成「小硕 x」+「WorkBuddy」两个文本节点，单节点识别会漏 → 按「含入口关键字但不含『小硕知道』」聚成 WB 组、热区取组内 rect 并集，点击用**并集中心坐标**（`pywinauto.mouse.click`）而非 `nodes[-1].click_input()`（树顺序不定，取末节点可能点到「小硕 x」）。②**首页轮播里有「小硕 × WorkBuddy」推广磁贴**，名字也含关键字，子串匹配会把它收进 WB 组、把并集热区撑成 `(521,667,1225,2571)` 大半个页面，坐标点落到页面中间点不动入口（连踩两轮，误判成「点击偶发失手」）。修法：`_is_entry_label` 过滤——入口标签是短名（≤20 字），磁贴名长且带「已选择/安装应用/打开应用/更新应用」，一律排除。修完并集恢复成 `(521,1261,622,1307)`、点一次 1s 内落详情页（落地文本从首页 5512 字缩到详情页 484 字，含「一键安装/华硕专属联名/AI办公」）。
- **行 25「已安装拉起 WB」两个坑**：①**装完向导「完成后运行」会自启 WB**，用「点击后新增进程」判拉起会假失败（WB 早在快照前就在跑、点入口只是把已有窗口调前台）→ 验拉起前先 `_kill_wb_procs` 杀干净并等退出，再点入口轮询 WB 进程（`workbuddy/xiaoshuo/claw`）出现。②**静默卸载只删注册表条目、留下安装目录**（`C:\Users\admin\AppData\Local\Programs\XiaoshuoClaw`），残留目录会让下一轮安装走「修复」分支、装不出注册表条目 → WB 条目没写 InstallLocation，从 `QuietUninstallString` 里卸载器路径反推父目录，收尾 `rmtree` 并断言目录也没了。`button_label` 要剥掉 NSIS 导航尾箭头（「下一步(&N) >」→「下一步」）才命中白名单。
- **行 24「隐私协议态」轻量复位路**：同意标记在用户级 `user.config` 的 **`Agreen` 设置**（`%LOCALAPPDATA%\AppStore\AsusMemberCenter.exe_Url_*\<版本>\user.config`），置 0 即回首跑未同意态，**不用重装、不用提权**（`hall_auto/product.py` 的 `agreement_config_path`/`read_agreen`/`set_agreen`）。未同意态主窗口整页是隐私协议页（同意/取消 + 隐私政策链接），首页内容完全不渲染、WB 入口根本不在 → 产品把全部内容（含 WB）门控在同意之后。两个坑：①首跑同意后首页窗和「欢迎使用」引导窗是同 pid 两个顶层窗、枚举顺序不固定，要扫该 pid 全部可见「华硕大厅」窗逐个试；②协议页窗口标题仍是「华硕大厅」（协议画在主窗内容区），要按窗内「同意/取消」按钮认，别按标题关键词。收尾要关首跑「欢迎使用」设备标签引导窗（点「我选好了」），否则下次启动仍弹、盖住首页影响坐标点击。

## 客户端自更新链路（安全验证行 7-13 的共同前提）

- **本机自更新链路不激活**（2026-09-17 探针实测，`reports/probe/update_link_probe.py`）：设置页「立即检查更新」（Button，name 精确「立即检查更新」、**无 aid**）`invoke()` 点击成功后，轮询 60s 内**零可观测结果**——无新顶层窗、无新进程映像、无更新/升级对话框、主窗无「已是最新/发现新版本」类文案（UIA Text 只抓到设置页自身静态标签），`C:\ProgramData\AppStore`（含 `download`）**始终不创建**、无任何包落地。截图 t3/t8/t15/t30/final 全程设置页原样。
- 结论：客户端没有向服务端要到比本机 1.6.11.4 更高的版本包（SN 未下发），自更新「下载→校验→安装」整条链在本机无从触发 → 覆盖对照行 7-13（合法/非法/伪造/第三方/Hash/升级验证）全部卡服务端下发，**非客户端缺陷、非脚本问题**，本地无法绕过。等服务端对本机 SN 下发更高版本包后，行 12/13 因版本复位手段已具备（P0 卸装往返）最易补。
- 顺带观察（待与产品核对，未定缺陷）：已是最版时点「立即检查更新」**无任何用户可见反馈**，用户点了不知道查没查、结果如何。

## 无障碍缺陷候选（合并报开发）
