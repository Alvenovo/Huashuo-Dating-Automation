# 考试陷阱集 · 最容易记错的地方

> [!important] 这一页为什么值得反复读
> 别人考你项目的时候，**不会问你"UIPI 是什么"，而是问"读到按钮文字是不是就能点了？"**——问的就是这些"听起来很合理，但其实是错的"判断。
>
> 这一页一共 10 条，每条都是：**❌ 大多数人第一反应会这么想 → ✅ 实际正确的是什么 → 🧠 怎么记住**。
>
> 读法建议：先只看 10 个「❌」标题，**自己先猜正确答案**，再往下看。猜错的当场印象最深。

---

## 陷阱 1：「读得到」就等于「点得动」

**❌ 错误想法**：非提权进程用 `WM_GETTEXT` 读到了提权窗口里按钮的文字，说明可以自动化它。

**✅ 正确**：UIPI 的白名单**只放行** `WM_GETTEXT`（读文字）和 `WM_GETTEXTLENGTH`（读长度）。`BM_CLICK`（点击）、`SetForegroundWindow`（抢焦点）、`PrintWindow`（截图）**全被挡**。

最坑的地方：被挡之后**不是报错，而是静默失败**——代码照跑、用例照过，你完全不知道按钮根本没被点。

**🧠 记忆**：**「能听见，但推不动」**——隔着一层玻璃。你可以读它的字，但你的手伸不进去。
（配套画面：`WM_GETTEXT` 是**耳朵**，`BM_CLICK` 是**手**。耳朵被放行，手被按住。）

→ [[02-UIPI边界]] · [[03-计划任务提权]]

## 陷阱 2：「UIA 树里有这个控件」就一定能找到它

**❌ 错误想法**：探针看到 `卸载(&U)` 按钮在控件树里，直接按名字点它就行。

**✅ 正确**：厂商卸载器是 NSIS 做的，**UIA 对它完全是瞎的**——报 0 个 descendants，还把每个子控件**误报成独立顶层窗**。

更狠的一层：卸载确认页有两块自绘按钮，**树里的位置和眼睛看到的位置左右正好相反**。
- 眼睛看到（OCR）：左「再想想」、右「狠心卸载」
- 树里读到：左 `卸载(&U)`、右 `取消(&C)`

所以铁律是：**只按文字点隐藏按钮，绝不猜坐标。**

**🧠 记忆**：**「菜单上有的菜，厨房里不一定做得出」**。菜单（UIA 树）是给人看的排版，厨房（真实控件）的摆法和菜单不一样。
（配套口诀：**不信坐标，只信文字**。）

→ [[02-UIA为什么有时是瞎的]] · [[04-自绘按钮左右相反]]

## 陷阱 3：进了「我的」页就能看到刚装的应用

**❌ 错误想法**：装完应用，切到卸载列表应该立刻看到它。

**✅ 正确**：卸载列表是系统卸载注册表的**一次性快照**，只在**进入页面那一刻**拉一次。装完当场看不到，**必须退出「我的」再重进**（或重启大厅）才刷新。

所以"装完立刻卸"的用例如果没逼列表重拉，得到的是**假失败**——被测产品没坏，是测试脚本自己看错了。

**🧠 记忆**：**「拍立得」**——按下快门那一刻照片就定型了。你后来搬家了，照片里还是老房子。
（配套口诀：**列表不是直播，是快照**。）

→ [[01-镜像快照陷阱]]

## 陷阱 4：登录后主窗口还是同一个对象

**❌ 错误想法**：登录前拿到的 `main` 对象，登录后继续用就行。

**✅ 正确**：登录后主窗口的 **UIA Name 从「华硕大厅」变成了「华硕应用商店」**（注意：**Win32 标题没变**）。按 `title_re` 匹配 UIA Name 的 `WindowSpecification` 在登录态**永远解析失败**，重试多少次都没用。

正确做法：改用 `concrete_main(pid, title_contains)`，按 **Win32 标题 + pid** 重新包一个句柄。

**🧠 记忆**：**「花名 vs 工牌」**——员工换了个花名，别人按花名找就找不到人了；但工牌上的 ID 一直没变。
（UIA Name = 花名，会变；Win32 标题 + pid = 工牌，不变。**找人就查工牌**。）

→ [[04-登录态句柄失效]]

## 陷阱 5：「列表空」就是接口坏了

**❌ 错误想法**：三个列表刷新不出来数据 → 报缺陷。

**✅ 正确**：**允许空，但必须区分「接口失败」和「本来就没有」**。
同步页未登录时**只有登录提示、没有列表**，这是**正常状态**，不是缺陷。

**🧠 记忆**：**「空货架 ≠ 超市倒闭」**——也可能只是还没开门（未登录）。
（配套口诀：**先看门开没开，再看货架空不空**。）

→ [[01-oracle优先选系统状态]]

## 陷阱 6：搜索没结果就是产品挂了

**❌ 错误想法**：搜 `qq` 没有结果 → 失败。

**✅ 正确**：方案里确实写了"无结果则失败，**不把运营下架默认为通过**"——这一条是对的，别推翻它。但要看语境：如果应用目录里**本来就没有** QQ 系应用，那应该**换一个稳定存在的词**（而且这个词要写进配置），而不是报产品缺陷。

**🧠 记忆**：**「先确认你要找的东西真的该在这儿」**。在图书馆找不到某本书，第一步是查这本书在不在馆藏里，而不是先骂图书馆。
（配套口诀：**关键词要配置化，别写死**。）

→ [[01-P0冒烟的本分]]

## 陷阱 7：「显示不一致」都是 bug

**❌ 错误想法**：首页有时长得不一样 → 缺陷。

**✅ 正确**：只比**结构是否就绪**——导航、内容区、搜索入口**是否都在**。**不比 Banner 文案**。
未登录 vs 已登录、会员 vs 非会员，首页看起来本来就不同，这算**身份差异**，不算 P0-04 缺陷。

**🧠 记忆**：**「只看骨架在不在，不看化妆化什么样」**。
（配套口诀：**比结构，不比文案**。）

→ [[01-P0冒烟的本分]]

## 陷阱 8：版本号可以只比前三段

**❌ 错误想法**：`1.6.8.17` 和 `1.6.8.20` 前三段都是 `1.6.8`，算通过。

**✅ 正确**：必须**四段完整字符串相等**。只比前三段会把 `1.6.8.17` 和 `1.6.8.20` 当成同一个版本——升级用例直接失效（它以为升上去了，其实没有）。

顺带一条：安装包名 `myappstore_1.6.8.17S_Setup.exe` → 版本号 `1.6.8.17`，规则是**去掉结尾的 `S`，大小写不敏感**。

**🧠 记忆**：**「一块钱也是钱」**——第四段再小也是版本号的一部分，不能四舍五入扔掉。
（配套口诀：**四段全等，一段都不能少**。）

→ [[02-配置与数据夹具化]]

## 陷阱 9：办公机也能跑安装用例

**❌ 错误想法**：装个包验证一下，办公机也行。

**✅ 正确**：办公机**不要**加 `--allow-install`。破坏性用例必须**门禁 + 提权**才跑。

原因很实在：办公机上大厅列表里**全是 QQ/微信/WPS 这类日常软件**，一旦误点"全部安装"，就真的往这台机器上装一堆东西——不是测试，是事故。

有一个额外坑：`InstallAllBtn`（同步页「全部安装」）和 `UpdateAllBtn`（更新页）属于**绝对不点**的黑名单。

**🧠 记忆**：**「这是别人正在用的机器，不是沙盘」**。
（配套口诀：**办公机默认只读；要动手，先过门禁**。）

→ [[03-标记体系与门禁]]

## 陷阱 10：`sleep` 够了就不用条件轮询

**❌ 错误想法**：等 3 秒再断言，够稳。

**✅ 正确**：固定等待**在慢机器上不可靠**（还没加载完就断言 → 假失败），**在快机器上又白浪费时间**。方案的做法是**条件轮询 + 超时**（`waiting.wait_until`）。

还有一层实测根因：就绪循环里每次取 `main.handle` / `process_id` **各约 1 秒**，所以必须**在循环外缓存**——这正是"首页停留过长"的二次根因。

**🧠 记忆**：**「等到条件成立，不是等到闹钟响」**。
（配套口诀：**重活别放循环里；循环外缓存**。）

→ [[03-等待机制演进]]

# 🎴 一页速记（10 条串成一串）

别人提问时，脑子里按这个顺序过一遍就行：

| # | 一句话主张 | 画面/口诀 |
|---|---|---|
| 1 | 读得到 ≠ 点得动 | 玻璃外看，手伸不进 |
| 2 | 树里有 ≠ 找得到 | 菜单有的菜，厨房不一定做得出 |
| 3 | 装完 ≠ 立刻看得到 | 拍立得，按下就定格 |
| 4 | 登录后窗口没"改名"？错，改了 | 找人就查工牌，别查花名 |
| 5 | 列表空 ≠ 接口坏 | 空货架不一定是超市倒闭 |
| 6 | 搜不到 ≠ 产品挂 | 先确认这本书在不在馆藏 |
| 7 | 长得不一样 ≠ 缺陷 | 只看骨架，不看化妆 |
| 8 | 前三段一样 ≠ 同版本 | 一块钱也是钱 |
| 9 | 办公机 ≠ 沙盘 | 别人正在用的机器，别乱点 |
| 10 | 等够时间 ≠ 等对条件 | 等条件成立，不是等闹钟 |

> [!tip] 背下来的省力方式
> 这 10 条其实是**三个母题**重复出现：
> - **母题 A「看得见 ≠ 动得了」** → 第 1、2 条（权限和协议的限制）
> - **母题 B「你看到的是旧信息」** → 第 3、4 条（快照、改名）
> - **母题 C「先确认预期，再判定失败」** → 第 5、6、7、8、10 条（别把"我理解错了"当成"产品坏了"）
> - **母题 D「环境安全第一」** → 第 9 条（只有它，所以要单独记）
>
> 记住 4 个母题，比背 10 条省力得多。
