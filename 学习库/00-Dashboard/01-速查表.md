## 📖 阅读前 · 3 个名词先搞懂

| 名词 | 说人话 | 打个比方 |
|---|---|---|
| **提权** | 用"管理员身份"跑程序 | 普通员工的卡刷不开仓库门，要用主管的钥匙卡 |
| **`-m` 后面那些词** | pytest 里的"标签"，用来只跑某一类用例 | 像超市货架标签，只推走"零食区"的车 |
| **plan任务（`schtasks`）** | 让系统代为执行一个高权限任务 | 你写一张**委托单**给系统，系统替你进仓库 |

## 🚀 跑法速查

| 要做什么 | 命令 | 机器/权限 |
|---|---|---|
| 改了解析逻辑，验纯计算 | `.\.venv\Scripts\python.exe -m pytest tests/unit -m unit` | 办公机，随时 |
| 装基线包 / 升最新包 | 管理员 PowerShell 跑 `tools\run_install_elevated.ps1` | 专用机 · **管理员** |
| 冒烟（P0-03/04/06/07） | `.\run_p0_launch.ps1` | 专用机 |
| P1-A 三个列表检测（不改状态） | `-m "apps and not destructive"` | 非提权可跑 |
| P1-A 真装真卸 | `MSYS_NO_PATHCONV=1 schtasks /Run /TN HallAutoP1` | **走计划任务，0 人工** |
| 登录套件 | `-m login`（需 `HALL_TEST_USER/PASSWORD`） | 凭据走环境变量 |
| 主题套件 | `-m settings` | 会重启一次大厅 |
| P2 安全验证 | `-m security` | 只写工作目录 |
| P2 WorkBuddy 非破坏 | `-m wb` | 绝不点「一键安装」 |
| 人在环（真发短信/真改密码） | `-m manual -s` | **只在用户自己终端** |

> [!warning] 三条最容易违反的约定
> 1. 本机 `python` **不在 PATH** → 一律 `.venv\Scripts\python.exe`，带 `-X utf8`
> 2. Git Bash 里 `schtasks /Run` 会被**路径转换**吃掉 → 必须加 `MSYS_NO_PATHCONV=1` 前缀
> 3. 办公机**不要** `--allow-install`

**🧠 记忆钩子**：**「本机 python 没装、斜杠会被吃、办公机别装东西」**
—— 三句话对应三条坑：①路径 ②转义 ③安全。

## 🎛 控件速查（写断言前必对）

| 位置 | 控件 | aid | 坑 |
|---|---|---|---|
| 首页 | 搜索框 | `SearchBarInput` | 原生 `Edit`，**不是网页控件** |
| 首页 | 必备结构 | `SearchBarInput` / `TabList` / `MainWeb` | 就绪判定**三件套** |
| 我的页 | 页面 | `Mine` | 进入时列表是**一次性快照** |
| 我的页 | 更新/卸载/同步页签 | `UpTabBtn` / `UnTabBtn` / `NoTabBtn` | |
| 我的页 | 全部更新 | `UpdateAllBtn` | 🚫 **红线：绝不点** |
| 我的页 | 全部安装 | `InstallAllBtn` | 🚫 **红线：绝不点** |
| 登录窗 | 手机号（账密页） | `MobileInputBox` | 注册页才叫 `MobileInput` |
| 登录窗 | 登录按钮 | `LoginBtn`（name「登录」） | 不勾协议是**灰的**，`invoke()` 无效 |
| 登录窗 | 发送验证码 | `CodeSendBtn` | name 是「发送验证码」；**点完从树里消失** |
| 设置页 | 主题三档 | `LightMode` / `DarkMode` / `AuroMode` | **只按 aid 找**，按名字会撞同名 ToolTip |
| 关于页 | 版本节点 | `VersionLabel` | UIA name 是占位符 `ver` → 只能**截图 OCR** |

**🧠 记忆钩子**：三个"名字最容易记混"的地方——
- **两个"全部"按钮 = 两个炸弹**（`InstallAllBtn` 安装版、`UpdateAllBtn` 更新版），见到就跑。
- **手机号输入框有两个名字**：账密页 `MobileInputBox`（带 Box），注册页 `MobileInput`（不带）→ **"账号页多一个盒子"**。
- **设置页主题只认 aid**：三档叫 `LightMode`/`DarkMode`/`AuroMode`（注意是 `Auro` 不是 `Auto`，拼写就这样，别自己"改对"）→ **"按名字找会撞同名提示"**。

## 🔢 版本口径速查

```
文件名  myappstore_1.6.8.17S_Setup.exe
              ↓ 取 1.6.8.17S
              ↓ 去掉末尾 S（大小写不敏感）
期望版本  1.6.8.17
              ↓ 字符串相等（不要只比前三段）
对照   注册表 DisplayVersion  +  AsusMemberCenter.exe FileVersion  +  关于页（OCR）
```

> [!tip] 为什么末尾 `S` 不进版本号
> `1.6.8.17S` 对应系统版本 `1.6.8.17`。忘了去 `S`，版本断言会**全线假失败**。

**🧠 记忆钩子**：**「包名带哨兵，系统不带」**
—— `S` 是安装包自己的标记（像商品包装上的"特惠"贴纸），**撕掉贴纸才是真价格**。
第二句：**「四段全等，一段都不能少」**（只比前三段 → `1.6.8.17` 和 `1.6.8.20` 会被当成同一个）。

## 📁 关键路径速查

| 项 | 值 |
|---|---|
| 安装目录 | `C:\Program Files (x86)\ASUS\ASUS Member Center` |
| 卸载注册表 | `HKLM\SOFTWARE\WOW6432Node\...\Uninstall\AsusMemberCenter` |
| 进程名 | `AsusMemberCenter.exe` |
| 下载缓存 | `C:\AsusMCenterDownload`（跑完要清） |
| 卸载器映像 | `%TEMP%\~nsuA.tmp\Au_.exe`（⚠️ **不在下载目录**） |
| 卸载命令 | 注册表 `UninstallString`（`asusUn.exe /S`），**不要去点控制面板** |
| 证据报告 | `reports\evidence\<日期_时间>\report.html` |

**🧠 记忆钩子**：**「卸载器会搬家」**
—— 它不在下载目录，而是临时跑到了 `%TEMP%\~nsuA.tmp\`。所以**要去查注册表问它现在住哪**，而不是按老地址找。
（延伸：进程名 `AsusMemberCenter.exe` 里有个 `Member`——**"会员中心"**，就是"华硕大厅"。）

## 🧭 遇到问题时的排查顺序

忘了该查哪儿时，按这个顺序想：

1. **"这东西的权威答案在哪？"** → 优先查系统状态（注册表 / `FileVersion`），别只信界面 → [[01-oracle优先选系统状态]]
2. **"窗口还认得出来吗？"** → 登录后 UIA Name 会变 → [[04-登录态句柄失效]]
3. **"是没加载完，还是真的没有？"** → 条件轮询看状态 → [[03-等待机制演进]]
4. **"列表是不是旧数据？"** → 退出重进逼它重拉 → [[01-镜像快照陷阱]]
5. **"这个操作需要管理员吗？"** → 要提权就走计划任务 → [[03-计划任务提权]]

**🧠 记忆钩子**：**「查档案 → 认窗口 → 等条件 → 刷列表 → 要权限」**
（五步顺口溜，对应上面 1–5。）
