# 03 · P2 易变内容抽检

> P2 的定位最特殊：**它测的是内容，而内容是易变的**。所以 P2 的断言必须写得极浅——只测"入口存在、能打开"，不测"里面写了什么"。

## 会员

**至少两个身份**：非会员 / 会员。

只断言：
- 入口**可见性**
- 权益页**能打开**
- 无权限操作有**明确拦截**

> [!warning] 明确不做的
> **不把具体价格文案写死。** 价格天天变，写死等于制造假失败。

## 活动

只断言：
- 活动**入口存在**
- 能打开
- 外链/内开**跳转发生**

**活动素材、时间、文案一律配置化或标「内容易变」。活动下线时套件跳过，不报 P0 红。**

> [!important] "跳过" vs "失败"的分界
> 活动下线 → **跳过**（因为没东西可测）。
> 活动入口该在却不在 → **失败**（产品问题）。
> 这个分界要靠配置或外部信号来表达，不能靠脚本猜。

## 为什么 P2 只能这么浅

把 P2 的三层抽象画出来就清楚了：

```
最浅：入口存在吗？      ← P2 测这层（稳定，几乎不会变）
中间：点了能打开吗？    ← P2 测这层（较稳定）
最深：内容写的是什么？  ← P2 不测（天天变，无法断言）
```

**越浅越稳定，越深越易变。** P2 的价值在于"漏斗没坏"，不在于"水好不好喝"。

## P2 实际扩展（本项目的落地）

本项目 P2 范围比原方案有所扩展，实际包含：

| 板块 | 内容 | 特点 |
|---|---|---|
| 会员/活动 | 入口与跳转抽检 | 原方案内容 |
| **安全验证** | 安装包/个人空间盘数字签名、控制面板信息、签章检查报告、清单对比 | 用公司内部工具（CheckAppV/SignCheck），**工具与受检包不进公开仓库** |
| **WorkBuddy 入口** | WB 入口集成 6 点 + 破坏性往返 | 含一条 `destructive` 需门禁 |

> [!tip] 安全验证的一个设计亮点
> 工具路径走 `config.local.yaml` 的 `security.tools_dir`，**没配自动 skip**。
> 好处：公开仓库里可以带着用例代码，但**内部工具名和受检包不进仓库**，同时在其他机器上不会因为缺工具而报红，只会 skip。
> **规律：敏感/环境相关的依赖，用"配置缺失则 skip"代替"硬编码路径"。**

## 清单对比的 oracle 设计

「安全清单 vs 安装包清单对比」这条（行 14）值得单独看，因为它的 oracle 设计很干净：

```
开发给的安全清单（一行一个相对包根路径）
        ↓
   集合比较（双向差异都判失败）
        ↓
包内实际文件索引（可配 scope：signable 只比可签名文件 / all 比全部）
```

`manifest_scope` 这个开关很关键：**如果清单只涵盖可签名文件，那就不该拿包里的 readme、图片去比**——否则会大面积假失败。

## 自测

> [!question]- Q1：为什么 P2 不把价格文案写死？
> 因为价格是**运营数据**，随时可调。写死后产品改价 → 用例失败 → 但这不是缺陷。
> **判据：断言的对象如果是"会被人为频繁改动的运营内容"，就不该硬编码。**

> [!question]- Q2：活动下线时"跳过"而不是"失败"，这个决策依赖什么前提？
> 依赖**能区分"下线"和"入口该在却不在"**。
> 实现方式：配置里声明当前活动入口，或者用外部信号（如活动期时间窗）。
> 如果无法区分，就只能人工判断——这也是 P2 为什么叫"抽检"而不是"回归"。

> [!question]- Q3：`security.tools_dir` 没配就 skip，这个模式还能用在哪？
> 任何**环境依赖**场景：
> - 需要凭据的用例（`HALL_TEST_USER` 没设 → skip）
> - 需要夹具应用的用例（`fixture_apps.*` 为空 → skip）
> - 需要管理员权限的用例（未提权 → skip）
>
> 本项目的做法是统一的：**`configured()` 方法判断配置是否完整，不完整就 skip 并在报告里写明原因。**
> 好处：**同一份代码可以在不同完备度的机器上跑，不报假红。**

> [!question]- Q4：为什么 P2 的"入口存在"这类断言几乎不会假失败？
> 因为它测的是**产品架构层面的东西**（入口按钮在不在），而不是**内容层面的东西**（文案是什么）。
> 架构变化频率远低于内容变化频率。
> **推而广之：写断言时优先选择"变化频率低"的观测点。**
